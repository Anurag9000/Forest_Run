## Screenshot Capture

Use the deterministic capture script once a device is visible to `adb`:

```bash
JAVA_HOME=/opt/android-studio/jbr GRADLE_USER_HOME=/tmp/forest_run_gradle ./gradlew assembleDebug
scripts/capture_store_screenshots.sh
```

The script installs the debug APK, launches the app into the built-in deterministic scenarios, then writes raw PNG screenshots into:

- `screenshots/raw/`

Curate the final set after capture with:

```bash
scripts/curate_store_screenshots.py
```

This copies the approved raw files into:

- `screenshots/final/`

and writes:

- `screenshots/CURATED_SET.md`
