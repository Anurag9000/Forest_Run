## Integration and interpretation notes

- The accessibility pipeline is layered: `GameView` creates current presentation facts and the router/provider; semantics owns stable node/action rules; geometry maps those IDs to shared Garden/settings layout; announcement and availability trackers independently coalesce updates. This establishes source integration, not TalkBack or Switch Access acceptance.
- The deterministic scenario evidence path is internally connected across script → trace recorder → replay contract → evidence codec/store/verifier → candidate manifest/store/verifier. Current-source search found consumers in JVM tests and release/instrumentation-oriented code; code presence alone does not establish generated or accepted evidence artifacts.
- EntityManager is the gameplay integration center for encounter selection, collision/outcome resolution, persistence notifications, Bloom reactions, and optional Seeds. `CollisionRuntimeEffectAdapters` is an exception: its narrow port/adapters are not wired by production source in this snapshot.
- Journal views are projections over authoritative stores and managers. Collection, Garden, run legacy, route and page narrative layers do not constitute independent achievement or progression persistence.
- `EvaluationThrottle` is consumed by `LeitmotifManager` at `LeitmotifManager.kt:100-101,206-207,238,276,332-333`, so it is an integrated cadence helper; runtime behavior was not exercised. `CollisionRuntimeEffectAdapters` remains disconnected from production construction/callers and is explicitly described by its KDoc as a future integration. Disconnection alone does not establish a functional defect.
