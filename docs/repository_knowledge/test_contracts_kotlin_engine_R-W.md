## Grouped coverage and source-only caveats

- **Encounter/readability/fairness:** random encounter admission, action lead and seed-orb geometry use explicit maximum-speed, screen-size, input-delay, invalid-geometry and recovery-state fixtures. Their assertions provide intended guardrails, not proof of actual gameplay fairness or runtime collision behavior.
- **Relationship, story, and continuity presentation:** tests cover all entity catalogues or selected tracked families, persistence-backed history, monotonic unlocks, warm/strained distinctions and copy stability.
