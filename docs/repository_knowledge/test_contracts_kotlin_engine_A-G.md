## Scope and evidence boundary

This document records static assertions in inventoried JVM/Robolectric test sources under `app/src/test/java/com/anurag9000/forestrun/engine/`, selected by basename initial A–G. The repository was at `eeccc677107f69039dbf71053c18a9038d4b5ff6`; the inventory snapshot is `docs/repository_knowledge/file_inventory.json` (`baseline_commit` equals that revision). All 71 files below were recorded as `INVENTORIED` and `tracked_clean` in that inventory and were read in full for this batch.

These are **test-source contracts only**. No test, build, application workflow, or runtime check was run. Assertion presence does not establish that the assertions pass, that production behavior is correct, or that a complete feature has been validated. Property-style loops and concurrency cases are source specifications, not reported runtime results.

Excluded according to the assigned coverage boundary: `ApplicationIdentityTest.kt` and `GameStateManagerTest.kt` were already `PARTIALLY_INSPECTED`; `ForestGardenHistoryTest.kt` was already `FULLY_STATICALLY_INSPECTED`. They were not reread. Existing working-tree changes were preserved. No source file or shared ledger was modified for this artifact.

“Production references” below name the tested production symbols and, where the corresponding path was identified from the test contract, link the source file. A filename link is a navigation aid; it does not assert runtime integration beyond what the test itself exercises.
